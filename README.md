# WizardZ Landing Page

A responsive HTML5 landing page based on the supplied reference screenshot.

## Files
- `index.html` — semantic page markup and Bootstrap 5 layout.
- `css/style.css` — component styles, responsive breakpoints, illustrations, and logo marquee animation.
- `js/main.js` — reduced-motion handling for the moving brand logos.

## Run locally
Open `index.html` in a browser. Bootstrap 5 and the DM Sans font are loaded from CDNs, so an internet connection is needed for those external resources.

## Notes
- Brand logos animate from right to left and pause while hovered.
- The megaphone, service icons, and rocket scene are built with inline SVG/CSS, so no extra image files are required.
- Buttons and navigation links point to sections on the page. Replace the example contact email in `index.html` with your real address before publishing.
